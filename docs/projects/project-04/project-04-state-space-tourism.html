NoteExecutive summary

Title: State space models for South African accommodation demand

Section and topic: Section 2. Linear Gaussian state space models, the Kalman filter and smoother, maximum likelihood estimation through the prediction error decomposition, structural time series models (local level, local linear trend, damped trend, seasonal and AR components), and missing observations.

Type of project: Implementation from first principles, a simulation study, and model comparison on real-world data.

Question: Can a state space model, which handles missing observations without deleting or imputing anything, forecast monthly accommodation demand as well as the Project 1 SARIMA and the Project 3 regression and exponential smoothing models? And what does the model say about the demand lost during COVID-19?

Data: The Nile river annual flow (1871–1970, in base R) for validation, and real-world, publicly available data from Statistics South Africa, Tourist Accommodation release P6410, series B64100 (stay unit nights sold, total industry, thousands), monthly, January 2015 to June 2026. Source details are in Section 5.1.

Methods: I write my own Kalman filter (with missing observations), Kalman smoother, log likelihood and forecasting functions for a general univariate state space model, and estimate the variances by maximum likelihood. The code is validated by reproducing the published local level results for the Nile data, by a missing-data experiment, and by a simulation study with known parameters. I then fit four structural models to the log accommodation series with the COVID months treated as missing, compare them by AIC and residual diagnostics, use the smoother to estimate the demand that would have been sold without COVID, and evaluate the forecasts on the same test set as Projects 1 and 3 and by rolling-origin cross-validation.

Key findings: See Section 8.1.

What I would do differently: Use the exact diffuse initialisation instead of the large-variance approximation, and add the Project 3 intervention terms to the state space model so that the COVID months can be used instead of skipped.

Detailed analysis: the sections below.

1 Introduction and research question

Projects 1 and 3 dealt with the COVID-19 collapse in three ways: deleting the months (SARIMA with missing values), modelling them (regression with intervention terms) and imputing them (so that exponential smoothing could be used). Each had a cost. The intervention model needs the shape of the shock to be specified, and imputation treats invented values as data.

State space models offer a fourth route. The series is described by unobserved components (a level, a slope, a seasonal pattern) that evolve over time, and the Kalman filter updates the estimates of these components one observation at a time. When an observation is missing the filter simply skips the update step, so the COVID months can be left out without breaking the time ordering and without inventing values. The Kalman smoother then gives an estimate, with uncertainty, of where the components were during the gap: in other words, what demand would have been without the pandemic.

The same machinery sits behind many of the models used in earlier projects. ARIMA() evaluates its likelihood with a Kalman filter, which is how the Project 1 SARIMA coped with the missing COVID months, and every ETS model from Project 3 is a state space model in innovations form. Building the filter myself is a way of opening that black box.

Research question. Can structural state space models, estimated with my own Kalman filter and with the COVID months treated as missing, match the Project 1 and Project 3 models in forecasting accommodation demand, and how much demand do they estimate was lost to COVID-19?

2 The linear Gaussian state space model

Following Durbin and Koopman (2012), a univariate linear Gaussian state space model has an observation equation and a state equation:

\[ \begin{aligned} y_t &= Z^\top \alpha_t + \varepsilon_t, & \varepsilon_t &\sim N(0, H), \\ \alpha_{t+1} &= T \alpha_t + R \eta_t, & \eta_t &\sim N(0, Q), \qquad \alpha_1 \sim N(a_1, P_1). \end{aligned} \]

\(\alpha_t\) is the \(m \times 1\) state vector (the unobserved components), \(Z\) picks out the combination of states that is observed, \(T\) says how the states move from one period to the next, and \(R\) and \(Q\) describe the random shocks to the states. Different choices of \(Z\), \(T\), \(R\) and \(Q\) give different models; the code below never changes, only the system matrices do.

2.1 The Kalman filter

Write \(a_t = E(\alpha_t \mid y_1, \dots, y_{t-1})\) and \(P_t = \text{Var}(\alpha_t \mid y_1, \dots, y_{t-1})\) for the one-step predicted state and its variance. For each \(t\) the filter computes

\[ \begin{aligned} v_t &= y_t - Z^\top a_t, & F_t &= Z^\top P_t Z + H, & K_t &= T P_t Z / F_t, \\ a_{t+1} &= T a_t + K_t v_t, & P_{t+1} &= T P_t T^\top - K_t K_t^\top F_t + R Q R^\top . \end{aligned} \]

\(v_t\) is the one-step prediction error (the innovation), \(F_t\) its variance and \(K_t\) the Kalman gain, which says how much of the surprise \(v_t\) is passed on to the state estimate. If \(y_t\) is missing, there is no innovation, so the update is skipped: \(a_{t+1} = T a_t\) and \(P_{t+1} = T P_t T^\top + R Q R^\top\). The state is carried forward by the model alone and its variance grows.

2.2 The likelihood

Because the innovations are independent with variances \(F_t\), the log likelihood is the prediction error decomposition

\[ \log L = -\frac{1}{2} \sum_{t} \left( \log 2\pi + \log F_t + \frac{v_t^2}{F_t} \right), \]

summed over the observed \(t\) only. This is what makes maximum likelihood with missing data straightforward: missing months contribute nothing. The unknown variances are estimated by maximising \(\log L\) numerically (on the log scale, so they stay positive).

Initialisation. The initial level and seasonal effects are unknown, so I use a diffuse prior: \(a_1 = 0\) and \(P_1 = \kappa I\) with \(\kappa = 10^7\). The first \(d\) innovations, where \(d\) is the number of non-stationary states, have huge variances and carry no information about the parameters, so they are left out of the likelihood. This is the large-\(\kappa\) approximation to the exact diffuse filter in Durbin and Koopman (2012, Chapter 5).

2.3 The Kalman smoother

The filter uses only past data. The smoother uses all of it: working backwards with \(L_t = T - K_t Z^\top\), \(r_n = 0\) and \(N_n = 0\),

\[ r_{t-1} = Z v_t / F_t + L_t^\top r_t, \qquad N_{t-1} = Z Z^\top / F_t + L_t^\top N_t L_t, \]

with \(r_{t-1} = T^\top r_t\) and \(N_{t-1} = T^\top N_t T\) when \(y_t\) is missing. The smoothed state and its variance are then \(\hat\alpha_t = a_t + P_t r_{t-1}\) and \(V_t = P_t - P_t N_{t-1} P_t\). Inside a gap of missing observations, the smoother bridges between the data on either side.

2.4 Forecasting

Forecasting is the filter run with every future observation missing: from \(a_{n+1}\) and \(P_{n+1}\), repeat \(a \leftarrow T a\) and \(P \leftarrow T P T^\top + RQR^\top\). The \(h\)-step forecast of \(y\) is \(Z^\top a\) with variance \(Z^\top P Z + H\).

3 Implementation

Code 
# Kalman filter for a univariate linear Gaussian state space model ----------
# y may contain NA (missing observations). Returns predicted states a_t,
# variances P_t, innovations v_t, their variances F_t and the gains K_t.
kfilter <- function(y, sys) {
  Z <- sys$Z; H <- sys$H; Tm <- sys$T
  RQR <- sys$R %*% sys$Q %*% t(sys$R)
  n <- length(y); m <- length(sys$a1)
  a <- matrix(0, n + 1, m); P <- array(0, c(m, m, n + 1))
  v <- Fv <- rep(NA_real_, n); K <- matrix(0, n, m)
  a[1, ] <- sys$a1; P[, , 1] <- sys$P1
  for (t in 1:n) {
    at <- a[t, ]; Pt <- P[, , t]
    if (is.na(y[t])) {                         # missing: prediction step only
      a[t + 1, ]   <- Tm %*% at
      P[, , t + 1] <- Tm %*% Pt %*% t(Tm) + RQR
    } else {                                   # observed: update and predict
      PZ <- Pt %*% Z
      Ft <- as.numeric(crossprod(Z, PZ)) + H
      vt <- y[t] - sum(Z * at)
      Kt <- (Tm %*% PZ) / Ft
      a[t + 1, ]   <- Tm %*% at + Kt * vt
      P[, , t + 1] <- Tm %*% Pt %*% t(Tm) - Kt %*% t(Kt) * Ft + RQR
      v[t] <- vt; Fv[t] <- Ft; K[t, ] <- Kt
    }
  }
  list(a = a, P = P, v = v, F = Fv, K = K, n = n)
}

# Log likelihood (prediction error decomposition), dropping the first d
# observed innovations because of the diffuse initialisation
kloglik <- function(kf, d) {
  ok <- which(!is.na(kf$v))
  ok <- ok[-seq_len(d)]
  -0.5 * sum(log(2 * pi) + log(kf$F[ok]) + kf$v[ok]^2 / kf$F[ok])
}

# Standardised innovations e_t = v_t / sqrt(F_t), after the diffuse period
std_innov <- function(kf, d) {
  e  <- kf$v / sqrt(kf$F)
  ok <- which(!is.na(e))
  e[ok[seq_len(d)]] <- NA
  e
}

# Kalman smoother (Durbin and Koopman 2012, Section 4.4) --------------------
ksmooth <- function(kf, y, sys) {
  Z <- sys$Z; Tm <- sys$T; n <- kf$n; m <- length(sys$a1)
  r <- rep(0, m); N <- matrix(0, m, m)
  ahat <- matrix(0, n, m); V <- array(0, c(m, m, n))
  for (t in n:1) {
    if (is.na(y[t])) {
      r <- crossprod(Tm, r)
      N <- t(Tm) %*% N %*% Tm
    } else {
      L <- Tm - kf$K[t, ] %*% t(Z)
      r <- Z * kf$v[t] / kf$F[t] + crossprod(L, r)
      N <- Z %*% t(Z) / kf$F[t] + t(L) %*% N %*% L
    }
    Pt <- kf$P[, , t]
    ahat[t, ] <- kf$a[t, ] + Pt %*% r
    V[, , t]  <- Pt - Pt %*% N %*% Pt
  }
  list(ahat = ahat, V = V)
}

# h-step forecasts: the filter run with all future observations missing -------
kforecast <- function(kf, sys, h) {
  a <- kf$a[kf$n + 1, ]; P <- kf$P[, , kf$n + 1]
  RQR <- sys$R %*% sys$Q %*% t(sys$R)
  mean <- var <- numeric(h)
  for (j in 1:h) {
    mean[j] <- sum(sys$Z * a)
    var[j]  <- as.numeric(t(sys$Z) %*% P %*% sys$Z) + sys$H
    a <- sys$T %*% a
    P <- sys$T %*% P %*% t(sys$T) + RQR
  }
  tibble(h = 1:h, mean = mean, var = var)
}

The four functions are about 90 lines of R in total. They know nothing about any particular model: each model is a function that turns a parameter vector into the system matrices \((Z, H, T, R, Q, a_1, P_1)\).

4 Validation

4.1 The Nile data: reproducing a published result

The local level model is the simplest state space model:

\[ y_t = \mu_t + \varepsilon_t, \qquad \mu_{t+1} = \mu_t + \xi_t, \qquad \varepsilon_t \sim N(0, \sigma^2_\varepsilon), \; \xi_t \sim N(0, \sigma^2_\xi), \]

so \(m = 1\), \(Z = T = R = 1\), \(H = \sigma^2_\varepsilon\) and \(Q = \sigma^2_\xi\). Durbin and Koopman (2012, Section 2.10) fit it to the annual flow of the Nile at Aswan (1871–1970) and report maximum likelihood estimates \(\hat\sigma^2_\varepsilon = 15099\) and \(\hat\sigma^2_\xi = 1469.1\), with a log likelihood of \(-632.54\). Reproducing these numbers is a direct test of my filter, likelihood and optimiser.

Code

4.2 Link to exponential smoothing

For the local level model the Kalman gain converges quickly to a constant \(\bar K\), and once it has, the filter is \(a_{t+1} = a_t + \bar K (y_t - a_t)\): simple exponential smoothing with \(\alpha = \bar K\). Theory gives \(\bar K = \bar P / (\bar P + \sigma^2_\varepsilon)\) with \(\bar P = \sigma^2_\varepsilon \left(q + \sqrt{q^2 + 4q}\right)/2\) and \(q = \sigma^2_\xi / \sigma^2_\varepsilon\).

Code

nile_tsb <- as_tsibble(Nile)

  filter(term == "alpha") |> pull(estimate)

The filter’s gain settles at \(\bar K\) = 0.2670, the formula gives 0.2670, and fitting simple exponential smoothing to the Nile with ETS(A,N,N) in fable gives \(\hat\alpha\) = 0.2455. The small difference with the ETS estimate comes from the different treatment of the start of the series (ETS estimates the initial level as a parameter). This is the clearest link between Projects 3 and 4: an exponential smoothing method is the steady state of a Kalman filter, and the smoothing parameter is determined by the signal-to-noise ratio \(q\). A noisy series (small \(q\)) gets a small \(\alpha\); a series whose level moves a lot relative to the noise gets an \(\alpha\) near 1, which is what happened when ETS was fitted to the raw COVID data in Project 3.

4.3 Simulation study: how well are the variances estimated?

The Nile confidence intervals suggest that the variances are imprecisely estimated. To see how my estimator behaves when the truth is known, I simulate series of length 100 from a local level model with \(\sigma^2_\varepsilon = 15000\) in two settings: \(\sigma^2_\xi = 1500\) (signal-to-noise ratio \(q = 0.1\), close to the Nile estimates) and \(\sigma^2_\xi = 300\) (\(q = 0.02\), a level that moves much more slowly relative to the noise). For each of 300 series per setting I estimate both variances with my code and check whether the 95% interval for the 101st observation contains the simulated value.

Code 
sim_one <- function(n = 100, s2e = 15000, s2x = 1500) {
  mu <- 1000 + cumsum(c(0, rnorm(n, 0, sqrt(s2x))))       # n + 1 levels
  y  <- mu + rnorm(n + 1, 0, sqrt(s2e))
  fit <- optim(log(c(var(y[1:n]) / 2, var(y[1:n]) / 20)), nile_negll,
               y = y[1:n], method = "BFGS")
  kf <- kfilter(y[1:n], local_level(fit$par))
  fc <- kforecast(kf, local_level(fit$par), 1)
  tibble(s2e_hat = exp(fit$par[1]), s2x_hat = exp(fit$par[2]),
         covered = abs(y[n + 1] - fc$mean) <= 1.96 * sqrt(fc$var),
         converged = fit$convergence == 0)
}

The irregular variance is estimated well in both settings (relative RMSE about 0.18), but the level variance is much less precise (Table 2, Figure 2): its relative RMSE is 0.58 when \(q = 0.1\) and 1.01 when \(q = 0.02\). With \(q = 0.1\) the level variance is estimated at essentially zero (below 5% of its true value) in 1% of the samples, but with \(q = 0.02\) this happens in 8%. This is the pile-up problem: when the level moves slowly relative to the noise, the likelihood often has its maximum on the boundary (a fixed level), even though the true variance is positive. Despite this, the one-step 95% forecast intervals cover the next observation in 94.3% and 95.0% of the simulations, close to the nominal level, because forecasts depend on the parameters mainly through the gain \(\bar K\), which is better determined than either variance on its own. The lesson for the tourism models is to expect some variance estimates on the boundary and to judge the models by their innovations and forecasts rather than by the individual variances.

5.2 Four structural models

All four models are written for \(y_t = \log(\text{nights}_t)\) and share a seasonal component in dummy form, \(s_{t+1} = -\sum_{j=0}^{10} s_{t-j} + \omega_t\), so that the seasonal effects sum to approximately zero over a year and can evolve slowly. They differ in the trend and in whether a short-run AR(1) component \(c_t\) is added:

Model Trend Extra component States \(m\)
BSM (basic structural model) Local linear trend: \(\mu_{t+1} = \mu_t + \nu_t + \xi_t\), \(\nu_{t+1} = \nu_t + \zeta_t\) none 13
Level + seasonal Local level: \(\mu_{t+1} = \mu_t + \xi_t\) none 12
Damped trend \(\mu_{t+1} = \mu_t + \nu_t + \xi_t\), \(\nu_{t+1} = \phi \nu_t + \zeta_t\), \(0 < \phi < 1\) none 13
Damped trend + AR(1) as above \(c_{t+1} = \rho c_t + \kappa_t\) 14

and in each case \(y_t = \mu_t + s_t\, (+\, c_t) + \varepsilon_t\). The damped trend model is the state space counterpart of the damped Holt–Winters method that did best in Project 3, and the level + seasonal model corresponds to ETS(A,N,A). The AR(1) component addresses the diagnostic failure of the StructTS() model in an earlier version of Project 3: it allows short-lived deviations from the trend that persist for a few months.

Code 
# Build the system matrices for one of the structural models ------------------
# trend: "llt" (local linear trend), "ll" (local level), "damped"
param_names <- function(trend, ar) {
  c("eps", "level", if (trend != "ll") "slope", "seas",
    if (trend == "damped") "phi", if (ar) c("ar_var", "rho"))
}

unpack <- function(theta, trend, ar) {
  nm <- param_names(trend, ar)
  p  <- as.list(exp(theta)); names(p) <- nm
  if (trend == "damped") p$phi <- 0.98 * plogis(theta[nm == "phi"])   # phi in (0, 0.98)
  if (ar)                p$rho <- tanh(theta[nm == "rho"])             # rho in (-1, 1)
  if (trend == "ll")     p$slope <- NA
  p
}

structural_sys <- function(p, trend, ar) {
  n_tr <- if (trend == "ll") 1 else 2
  m <- n_tr + 11 + ar
  Tm <- matrix(0, m, m); Z <- numeric(m)
  Tm[1, 1] <- 1; Z[1] <- 1                                  # level
  if (n_tr == 2) {                                          # slope
    Tm[1, 2] <- 1
    Tm[2, 2] <- if (trend == "damped") p$phi else 1
  }
  s1 <- n_tr + 1                                            # seasonal block (11 states)
  Tm[s1, s1:(s1 + 10)] <- -1
  Tm[(s1 + 1):(s1 + 10), s1:(s1 + 9)] <- diag(10)
  Z[s1] <- 1
  if (ar) { Tm[m, m] <- p$rho; Z[m] <- 1 }                  # AR(1) component
  shock_rows <- c(1, if (n_tr == 2) 2, s1, if (ar) m)
  shock_var  <- c(p$level, if (n_tr == 2) p$slope, p$seas, if (ar) p$ar_var)
  R <- matrix(0, m, length(shock_rows))
  R[cbind(shock_rows, seq_along(shock_rows))] <- 1
  P1 <- diag(1e7, m)                                        # diffuse prior
  if (ar) P1[m, m] <- p$ar_var / (1 - p$rho^2)              # stationary prior for c_t
  list(Z = matrix(Z), H = p$eps, T = Tm, R = R,
       Q = diag(shock_var, length(shock_var)), a1 = rep(0, m), P1 = P1)
}

d_diffuse <- 13   # same number of dropped innovations for every model, so AIC is comparable

ssm_negll <- function(theta, y, trend, ar) {
  -kloglik(kfilter(y, structural_sys(unpack(theta, trend, ar), trend, ar)), d = d_diffuse)
}

# Maximum likelihood with several starting values (the surface is flat near the boundary)
fit_structural <- function(y, trend, ar, start = NULL) {
  nm <- param_names(trend, ar)
  th0 <- c(eps = log(1e-3), level = log(1e-3), slope = log(1e-5), seas = log(1e-5),
           phi = qlogis(0.9 / 0.98), ar_var = log(1e-3), rho = atanh(0.5))[nm]
  starts <- if (is.null(start)) list(th0, th0 + 0.5, th0 - 1) else list(start)
  best <- NULL
  for (s in starts) {
    o <- optim(s, ssm_negll, y = y, trend = trend, ar = ar, method = "BFGS",
               control = list(maxit = 500))
    o <- optim(o$par, ssm_negll, y = y, trend = trend, ar = ar, method = "Nelder-Mead",
               control = list(maxit = 4000))
    if (is.null(best) || o$value < best$value) best <- o
  }
  p   <- unpack(best$par, trend, ar)
  sys <- structural_sys(p, trend, ar)
  kf  <- kfilter(y, sys)
  list(theta = best$par, p = p, sys = sys, kf = kf, loglik = -best$value,
       k = length(nm), trend = trend, ar = ar, converged = best$convergence == 0)
}

Several patterns stand out (Table 3).

  • The irregular variance is essentially zero in every model. All short-run noise is absorbed by the level, so on the log scale the series behaves like a random-walk level plus a slowly changing seasonal pattern. This is the boundary problem from the simulation study, and it means the individual variances should not be over-interpreted.
  • The slope barely moves. In the BSM the slope variance is 9.8e-11, so the slope is effectively a fixed drift estimated from the whole sample.
  • Damping. The damped trend model estimates \(\phi\) = 0.901, so a change in the slope loses 10% of its effect each month.
  • The AR(1) component adds little. Its log likelihood is only 0.10 higher than the damped trend model’s, for two extra parameters, so AIC rejects it.

# Project 3 imputation of the COVID window (regression on the non-COVID months)
impute_covid <- function(df) {
  n_win <- month_num(covid_end) - month_num(covid_start) + 2
  df <- df |>
    as_tibble() |>
    mutate(t = row_number(), mon = factor(month(as.Date(Month))),
           in_win = Month >= covid_start & Month <= covid_end,
           ramp = pmin(pmax((month_num(Month) - month_num(covid_start) + 1) / n_win, 0), 1),
           y_obs = if_else(in_win, NA_real_, log(nights)))
  fit <- lm(y_obs ~ t + mon + ramp, data = df)
  df |>
    mutate(nights_imp = if_else(in_win, exp(predict(fit, newdata = df)), nights)) |>
    select(Month, nights, nights_imp, period)
}

ref_forecasts <- function(d, h) {
  dB <- d |> mutate(nights = if_else(period == "COVID window", NA_real_, nights))
  dI <- impute_covid(d) |> as_tsibble(index = Month)
  summ <- function(fc) {
    dist <- fc[[fabletools::distribution_var(fc)]]
    tibble(.model = fc$.model, Month = fc$Month, mean = fc$.mean,
           lo95 = quantile(dist, 0.025), hi95 = quantile(dist, 0.975))

                                ETS(log(nights_imp) ~ error("A") + trend("Ad") + season("A"))),

  )
}

Test set. The best state space model on the test set is Damped trend + AR(1) (RMSE 89.6), against 132.6 for seasonal naive, 101.6 for the Project 1 SARIMA and 72.5 for the Project 3 damped Holt–Winters model. All four state space models under-forecast (positive bias): demand grew faster in 2024–2026 than the models’ level and trend imply. The 95% intervals of the state space models cover at least 100% of the test months, but they are wide (mean width 629 thousand nights for the best model, against 545 for the SARIMA): with a random-walk level and no irregular noise, all the uncertainty accumulates in the level as the horizon grows.

Cross-validation. Over 13 origins the best model is SARIMA (Project 1) (RMSE 83.5) and the best state space model is Level + seasonal (RMSE 92.4). 8 Discussion

8.1 Key findings

  1. My implementation is correct. It reproduces the published Nile estimates (\(\hat\sigma^2_\varepsilon\) = 15,100, \(\hat\sigma^2_\xi\) = 1,468.4, log likelihood -632.54), handles missing observations as theory predicts, and its steady-state gain is close to the simple exponential smoothing parameter estimated by ETS() (0.267 against 0.246).
  2. Variances are hard to estimate. In the simulation study the level variance was estimated at essentially zero in 8% of samples when the signal-to-noise ratio was low (\(q = 0.02\)), yet the forecast intervals still covered 95% of the next observations.
  3. Treating COVID as missing works for state space models. All four structural models fitted with the COVID months skipped pass the white noise test on their innovations. The earlier StructTS() failure was largely an optimisation problem: my estimates have a log likelihood 13.8 units higher.
  4. The trend decides the forecasts. The Level + seasonal model has the lowest AIC; on the test set Damped trend + AR(1) is the best state space model (RMSE 89.6), and the BSM with its fixed slope is the worst (RMSE 156.2).
  5. Demand lost to COVID-19. The smoother estimates that about 22.4 million stay unit nights (48% of expected demand) were lost between March 2020 and March 2022.

8.2 Issues and limitations

  • Approximate diffuse initialisation. Using \(\kappa = 10^7\) and dropping the first 13 innovations works (it reproduces the Nile results), but the exact diffuse filter is more accurate when the initial states matter, and with 13 diffuse states it uses up more than a year of data.
  • Boundary estimates. Several variances are estimated at or near zero. Likelihood ratio tests and AIC behave non-standardly on the boundary, so the AIC comparison is only a guide.
  • The counterfactual depends on the model. Inside the gap the smoother interpolates with a random-walk level, so the estimated path between the pre- and post-COVID levels is close to a straight line. A model in which the “no-COVID” world kept growing at the pre-2020 rate would give a different estimate of the demand lost.
  • Wide intervals. With no irregular noise the forecast uncertainty is all in the level and grows like a random walk, so the intervals are wide at longer horizons.
  • Same test window throughout. All projects use one test window and a short cross-validation period that both fall in the post-COVID recovery, which favours models that do not extrapolate a negative trend.

8.3 What I would do differently

I would implement the exact diffuse Kalman filter, add the Project 3 intervention terms as regression effects inside the state space model so that the COVID months can be used rather than skipped (combining the strengths of Projects 3 and 4), and try a multiplicative or log-normal observation model in the original units. A Bayesian treatment of the variances, with priors that keep them away from zero, would also address the boundary problem seen in the simulation study.

# Introduction and research question

Projects 1 and 3 dealt with the COVID-19 collapse in three ways: deleting the months (SARIMA with missing values), modelling them (regression with intervention terms) and imputing them (so that exponential smoothing could be used). Each had a cost. The intervention model needs the shape of the shock to be specified, and imputation treats invented values as data.

State space models offer a fourth route. The series is described by unobserved components (a level, a slope, a seasonal pattern) that evolve over time, and the Kalman filter updates the estimates of these components one observation at a time. When an observation is missing the filter simply skips the update step, so the COVID months can be left out without breaking the time ordering and without inventing values. The Kalman smoother then gives an estimate, with uncertainty, of where the components were during the gap: in other words, what demand would have been without the pandemic.

The same machinery sits behind many of the models used in earlier projects. `ARIMA()` evaluates its likelihood with a Kalman filter, which is how the Project 1 SARIMA coped with the missing COVID months, and every ETS model from Project 3 is a state space model in innovations form. Building the filter myself is a way of opening that black box.

**Research question.** *Can structural state space models, estimated with my own Kalman filter and with the COVID months treated as missing, match the Project 1 and Project 3 models in forecasting accommodation demand, and how much demand do they estimate was lost to COVID-19?*

# The linear Gaussian state space model

Following Durbin and Koopman (2012), a univariate linear Gaussian state space model has an observation equation and a state equation:

$$
\begin{aligned}
y_t &= Z^\top \alpha_t + \varepsilon_t, & \varepsilon_t &\sim N(0, H), \\
\alpha_{t+1} &= T \alpha_t + R \eta_t, & \eta_t &\sim N(0, Q), \qquad \alpha_1 \sim N(a_1, P_1).
\end{aligned}
$$

$\alpha_t$ is the $m \times 1$ state vector (the unobserved components), $Z$ picks out the combination of states that is observed, $T$ says how the states move from one period to the next, and $R$ and $Q$ describe the random shocks to the states. Different choices of $Z$, $T$, $R$ and $Q$ give different models; the code below never changes, only the system matrices do.

## The Kalman filter

Write $a_t = E(\alpha_t \mid y_1, \dots, y_{t-1})$ and $P_t = \text{Var}(\alpha_t \mid y_1, \dots, y_{t-1})$ for the one-step predicted state and its variance. For each $t$ the filter computes

$$
\begin{aligned}
v_t &= y_t - Z^\top a_t, & F_t &= Z^\top P_t Z + H, & K_t &= T P_t Z / F_t, \\
a_{t+1} &= T a_t + K_t v_t, & P_{t+1} &= T P_t T^\top - K_t K_t^\top F_t + R Q R^\top .
\end{aligned}
$$

$v_t$ is the one-step prediction error (the *innovation*), $F_t$ its variance and $K_t$ the Kalman gain, which says how much of the surprise $v_t$ is passed on to the state estimate. **If $y_t$ is missing**, there is no innovation, so the update is skipped: $a_{t+1} = T a_t$ and $P_{t+1} = T P_t T^\top + R Q R^\top$. The state is carried forward by the model alone and its variance grows.

## The likelihood

Because the innovations are independent with variances $F_t$, the log likelihood is the *prediction error decomposition*

$$
\log L = -\frac{1}{2} \sum_{t} \left( \log 2\pi + \log F_t + \frac{v_t^2}{F_t} \right),
$$

summed over the observed $t$ only. This is what makes maximum likelihood with missing data straightforward: missing months contribute nothing. The unknown variances are estimated by maximising $\log L$ numerically (on the log scale, so they stay positive).

**Initialisation.** The initial level and seasonal effects are unknown, so I use a *diffuse* prior: $a_1 = 0$ and $P_1 = \kappa I$ with $\kappa = 10^7$. The first $d$ innovations, where $d$ is the number of non-stationary states, have huge variances and carry no information about the parameters, so they are left out of the likelihood. This is the large-$\kappa$ approximation to the exact diffuse filter in Durbin and Koopman (2012, Chapter 5).

## The Kalman smoother

The filter uses only past data. The smoother uses all of it: working backwards with $L_t = T - K_t Z^\top$, $r_n = 0$ and $N_n = 0$,

$$
r_{t-1} = Z v_t / F_t + L_t^\top r_t, \qquad N_{t-1} = Z Z^\top / F_t + L_t^\top N_t L_t,
$$

with $r_{t-1} = T^\top r_t$ and $N_{t-1} = T^\top N_t T$ when $y_t$ is missing. The smoothed state and its variance are then $\hat\alpha_t = a_t + P_t r_{t-1}$ and $V_t = P_t - P_t N_{t-1} P_t$. Inside a gap of missing observations, the smoother bridges between the data on either side.

## Forecasting

Forecasting is the filter run with every future observation missing: from $a_{n+1}$ and $P_{n+1}$, repeat $a \leftarrow T a$ and $P \leftarrow T P T^\top + RQR^\top$. The $h$-step forecast of $y$ is $Z^\top a$ with variance $Z^\top P Z + H$.

# Implementation

```{r}
#| label: ssm-functions

# Kalman filter for a univariate linear Gaussian state space model ----------
# y may contain NA (missing observations). Returns predicted states a_t,
# variances P_t, innovations v_t, their variances F_t and the gains K_t.
kfilter <- function(y, sys) {
  Z <- sys$Z; H <- sys$H; Tm <- sys$T
  RQR <- sys$R %*% sys$Q %*% t(sys$R)
  n <- length(y); m <- length(sys$a1)
  a <- matrix(0, n + 1, m); P <- array(0, c(m, m, n + 1))
  v <- Fv <- rep(NA_real_, n); K <- matrix(0, n, m)
  a[1, ] <- sys$a1; P[, , 1] <- sys$P1
  for (t in 1:n) {
    at <- a[t, ]; Pt <- P[, , t]
    if (is.na(y[t])) {                         # missing: prediction step only
      a[t + 1, ]   <- Tm %*% at
      P[, , t + 1] <- Tm %*% Pt %*% t(Tm) + RQR
    } else {                                   # observed: update and predict
      PZ <- Pt %*% Z
      Ft <- as.numeric(crossprod(Z, PZ)) + H
      vt <- y[t] - sum(Z * at)
      Kt <- (Tm %*% PZ) / Ft
      a[t + 1, ]   <- Tm %*% at + Kt * vt
      P[, , t + 1] <- Tm %*% Pt %*% t(Tm) - Kt %*% t(Kt) * Ft + RQR
      v[t] <- vt; Fv[t] <- Ft; K[t, ] <- Kt
    }
  }
  list(a = a, P = P, v = v, F = Fv, K = K, n = n)
}

# Log likelihood (prediction error decomposition), dropping the first d
# observed innovations because of the diffuse initialisation
kloglik <- function(kf, d) {
  ok <- which(!is.na(kf$v))
  ok <- ok[-seq_len(d)]
  -0.5 * sum(log(2 * pi) + log(kf$F[ok]) + kf$v[ok]^2 / kf$F[ok])
}

# Standardised innovations e_t = v_t / sqrt(F_t), after the diffuse period
std_innov <- function(kf, d) {
  e  <- kf$v / sqrt(kf$F)
  ok <- which(!is.na(e))
  e[ok[seq_len(d)]] <- NA
  e
}

# Kalman smoother (Durbin and Koopman 2012, Section 4.4) --------------------
ksmooth <- function(kf, y, sys) {
  Z <- sys$Z; Tm <- sys$T; n <- kf$n; m <- length(sys$a1)
  r <- rep(0, m); N <- matrix(0, m, m)
  ahat <- matrix(0, n, m); V <- array(0, c(m, m, n))
  for (t in n:1) {
    if (is.na(y[t])) {
      r <- crossprod(Tm, r)
      N <- t(Tm) %*% N %*% Tm
    } else {
      L <- Tm - kf$K[t, ] %*% t(Z)
      r <- Z * kf$v[t] / kf$F[t] + crossprod(L, r)
      N <- Z %*% t(Z) / kf$F[t] + t(L) %*% N %*% L
    }
    Pt <- kf$P[, , t]
    ahat[t, ] <- kf$a[t, ] + Pt %*% r
    V[, , t]  <- Pt - Pt %*% N %*% Pt
  }
  list(ahat = ahat, V = V)
}

# h-step forecasts: the filter run with all future observations missing -------
kforecast <- function(kf, sys, h) {
  a <- kf$a[kf$n + 1, ]; P <- kf$P[, , kf$n + 1]
  RQR <- sys$R %*% sys$Q %*% t(sys$R)
  mean <- var <- numeric(h)
  for (j in 1:h) {
    mean[j] <- sum(sys$Z * a)
    var[j]  <- as.numeric(t(sys$Z) %*% P %*% sys$Z) + sys$H
    a <- sys$T %*% a
    P <- sys$T %*% P %*% t(sys$T) + RQR
  }
  tibble(h = 1:h, mean = mean, var = var)
}
```

The four functions are about 90 lines of R in total. They know nothing about any particular model: each model is a function that turns a parameter vector into the system matrices $(Z, H, T, R, Q, a_1, P_1)$.

## The Nile data: reproducing a published result {#sec-nile}

The local level model is the simplest state space model:

$$
y_t = \mu_t + \varepsilon_t, \qquad \mu_{t+1} = \mu_t + \xi_t, \qquad \varepsilon_t \sim N(0, \sigma^2_\varepsilon), \; \xi_t \sim N(0, \sigma^2_\xi),
$$

so $m = 1$, $Z = T = R = 1$, $H = \sigma^2_\varepsilon$ and $Q = \sigma^2_\xi$. Durbin and Koopman (2012, Section 2.10) fit it to the annual flow of the Nile at Aswan (1871–1970) and report maximum likelihood estimates $\hat\sigma^2_\varepsilon = 15099$ and $\hat\sigma^2_\xi = 1469.1$, with a log likelihood of $-632.54$. Reproducing these numbers is a direct test of my filter, likelihood and optimiser.

## Link to exponential smoothing

For the local level model the Kalman gain converges quickly to a constant $\bar K$, and once it has, the filter is $a_{t+1} = a_t + \bar K (y_t - a_t)$: simple exponential smoothing with $\alpha = \bar K$. Theory gives $\bar K = \bar P / (\bar P + \sigma^2_\varepsilon)$ with $\bar P = \sigma^2_\varepsilon \left(q + \sqrt{q^2 + 4q}\right)/2$ and $q = \sigma^2_\xi / \sigma^2_\varepsilon$.

A noisy series (small $q$) gets a small $\alpha$; a series whose level moves a lot relative to the noise gets an $\alpha$ near 1, which is what happened when ETS was fitted to the raw COVID data in Project 3.

## Simulation study: how well are the variances estimated?

## Four structural models

All four models are written for $y_t = \log(\text{nights}_t)$ and share a seasonal component in dummy form, $s_{t+1} = -\sum_{j=0}^{10} s_{t-j} + \omega_t$, so that the seasonal effects sum to approximately zero over a year and can evolve slowly. They differ in the trend and in whether a short-run AR(1) component $c_t$ is added:

| Model | Trend | Extra component | States $m$ |
|:--|:--|:--|:--|
| **BSM** (basic structural model) | Local linear trend: $\mu_{t+1} = \mu_t + \nu_t + \xi_t$, $\nu_{t+1} = \nu_t + \zeta_t$ | none | 13 |
| **Level + seasonal** | Local level: $\mu_{t+1} = \mu_t + \xi_t$ | none | 12 |
| **Damped trend** | $\mu_{t+1} = \mu_t + \nu_t + \xi_t$, $\nu_{t+1} = \phi \nu_t + \zeta_t$, $0 < \phi < 1$ | none | 13 |
| **Damped trend + AR(1)** | as above | $c_{t+1} = \rho c_t + \kappa_t$ | 14 |

and in each case $y_t = \mu_t + s_t\, (+\, c_t) + \varepsilon_t$. The damped trend model is the state space counterpart of the damped Holt–Winters method that did best in Project 3, and the level + seasonal model corresponds to ETS(A,N,A). The AR(1) component addresses the diagnostic failure of the `StructTS()` model in an earlier version of Project 3: it allows short-lived deviations from the trend that persist for a few months.

```{r}
#| label: model-builder

# Build the system matrices for one of the structural models ------------------
# trend: "llt" (local linear trend), "ll" (local level), "damped"
param_names <- function(trend, ar) {
  c("eps", "level", if (trend != "ll") "slope", "seas",
    if (trend == "damped") "phi", if (ar) c("ar_var", "rho"))
}

unpack <- function(theta, trend, ar) {
  nm <- param_names(trend, ar)
  p  <- as.list(exp(theta)); names(p) <- nm
  if (trend == "damped") p$phi <- 0.98 * plogis(theta[nm == "phi"])   # phi in (0, 0.98)
  if (ar)                p$rho <- tanh(theta[nm == "rho"])             # rho in (-1, 1)
  if (trend == "ll")     p$slope <- NA
  p
}

structural_sys <- function(p, trend, ar) {
  n_tr <- if (trend == "ll") 1 else 2
  m <- n_tr + 11 + ar
  Tm <- matrix(0, m, m); Z <- numeric(m)
  Tm[1, 1] <- 1; Z[1] <- 1                                  # level
  if (n_tr == 2) {                                          # slope
    Tm[1, 2] <- 1
    Tm[2, 2] <- if (trend == "damped") p$phi else 1
  }
  s1 <- n_tr + 1                                            # seasonal block (11 states)
  Tm[s1, s1:(s1 + 10)] <- -1
  Tm[(s1 + 1):(s1 + 10), s1:(s1 + 9)] <- diag(10)
  Z[s1] <- 1
  if (ar) { Tm[m, m] <- p$rho; Z[m] <- 1 }                  # AR(1) component
  shock_rows <- c(1, if (n_tr == 2) 2, s1, if (ar) m)
  shock_var  <- c(p$level, if (n_tr == 2) p$slope, p$seas, if (ar) p$ar_var)
  R <- matrix(0, m, length(shock_rows))
  R[cbind(shock_rows, seq_along(shock_rows))] <- 1
  P1 <- diag(1e7, m)                                        # diffuse prior
  if (ar) P1[m, m] <- p$ar_var / (1 - p$rho^2)              # stationary prior for c_t
  list(Z = matrix(Z), H = p$eps, T = Tm, R = R,
       Q = diag(shock_var, length(shock_var)), a1 = rep(0, m), P1 = P1)
}

d_diffuse <- 13   # same number of dropped innovations for every model, so AIC is comparable

ssm_negll <- function(theta, y, trend, ar) {
  -kloglik(kfilter(y, structural_sys(unpack(theta, trend, ar), trend, ar)), d = d_diffuse)
}

# Maximum likelihood with several starting values (the surface is flat near the boundary)
fit_structural <- function(y, trend, ar, start = NULL) {
  nm <- param_names(trend, ar)
  th0 <- c(eps = log(1e-3), level = log(1e-3), slope = log(1e-5), seas = log(1e-5),
           phi = qlogis(0.9 / 0.98), ar_var = log(1e-3), rho = atanh(0.5))[nm]
  starts <- if (is.null(start)) list(th0, th0 + 0.5, th0 - 1) else list(start)
  best <- NULL
  for (s in starts) {
    o <- optim(s, ssm_negll, y = y, trend = trend, ar = ar, method = "BFGS",
               control = list(maxit = 500))
    o <- optim(o$par, ssm_negll, y = y, trend = trend, ar = ar, method = "Nelder-Mead",
               control = list(maxit = 4000))
    if (is.null(best) || o$value < best$value) best <- o
  }
  p   <- unpack(best$par, trend, ar)
  sys <- structural_sys(p, trend, ar)
  kf  <- kfilter(y, sys)
  list(theta = best$par, p = p, sys = sys, kf = kf, loglik = -best$value,
       k = length(nm), trend = trend, ar = ar, converged = best$convergence == 0)
}
```

* **The irregular variance is essentially zero in every model.** All short-run noise is absorbed by the level, so on the log scale the series behaves like a random-walk level plus a slowly changing seasonal pattern. * **The slope barely moves.** In the BSM the slope variance is `r sci(sv("BSM", "Slope"))`, so the slope is effectively a fixed drift estimated from the whole sample.

impute_covid <- function(df) {
  n_win <- month_num(covid_end) - month_num(covid_start) + 2
  df <- df |>
    as_tibble() |>
    mutate(t = row_number(), mon = factor(month(as.Date(Month))),
           in_win = Month >= covid_start & Month <= covid_end,
           ramp = pmin(pmax((month_num(Month) - month_num(covid_start) + 1) / n_win, 0), 1),
           y_obs = if_else(in_win, NA_real_, log(nights)))
  fit <- lm(y_obs ~ t + mon + ramp, data = df)
  df |>
    mutate(nights_imp = if_else(in_win, exp(predict(fit, newdata = df)), nights)) |>
    select(Month, nights, nights_imp, period)
}

# Discussion

## Key findings {#sec-findings}

1. **My implementation is correct.** It reproduces the published Nile estimates ($\hat\sigma^2_\varepsilon$ = `r fmt(nile_var[1], 0)`, $\hat\sigma^2_\xi$ = `r fmt(nile_var[2], 1)`, log likelihood `r fmt(-nile_opt$value, 2)`), handles missing observations as theory predicts, and its steady-state gain is close to the simple exponential smoothing parameter estimated by `ETS()` (`r fmt(K_bar_filter, 3)` against `r fmt(alpha_ses, 3)`).
2. **Variances are hard to estimate.** In the simulation study the level variance was estimated at essentially zero in `r pct(sim_zero_lo)` of samples when the signal-to-noise ratio was low ($q = 0.02$), yet the forecast intervals still covered `r pct(sim_cover)` of the next observations.
3. **Treating COVID as missing works for state space models.** All four structural models fitted with the COVID months skipped `r if (min(ssm_tbl$"Ljung-Box p") > 0.05) "pass the white noise test on their innovations" else "were checked against the white noise standard"`. The earlier `StructTS()` failure was largely an optimisation problem: my estimates have a log likelihood `r fmt(sv("BSM", "Log lik") - st_ll_mine, 1)` units higher.
4. **The trend decides the forecasts.** The `r best_aic` model has the lowest AIC; on the test set `r best_ssm_test` is the best state space model (RMSE `r fmt(rg(best_ssm_test, "RMSE"))`), and the BSM with its fixed slope is the worst (RMSE `r fmt(rg("BSM", "RMSE"))`).
5. **Demand lost to COVID-19.** The smoother estimates that about `r fmt(total_lost / 1000, 1)` million stay unit nights (`r pct(share_lost)` of expected demand) were lost between March 2020 and March 2022.

## Issues and limitations

* **Approximate diffuse initialisation.** Using $\kappa = 10^7$ and dropping the first 13 innovations works (it reproduces the Nile results), but the exact diffuse filter is more accurate when the initial states matter, and with 13 diffuse states it uses up more than a year of data.
* **Boundary estimates.** Several variances are estimated at or near zero. Likelihood ratio tests and AIC behave non-standardly on the boundary, so the AIC comparison is only a guide.
* **The counterfactual depends on the model.** Inside the gap the smoother interpolates with a random-walk level, so the estimated path between the pre- and post-COVID levels is close to a straight line. A model in which the "no-COVID" world kept growing at the pre-2020 rate would give a different estimate of the demand lost.
* **Wide intervals.** With no irregular noise the forecast uncertainty is all in the level and grows like a random walk, so the intervals are wide at longer horizons.
* **Same test window throughout.** All projects use one test window and a short cross-validation period that both fall in the post-COVID recovery, which favours models that do not extrapolate a negative trend.

## What I would do differently

I would implement the exact diffuse Kalman filter, add the Project 3 intervention terms as regression effects inside the state space model so that the COVID months can be used rather than skipped (combining the strengths of Projects 3 and 4), and try a multiplicative or log-normal observation model in the original units. A Bayesian treatment of the variances, with priors that keep them away from zero, would also address the boundary problem seen in the simulation study.
